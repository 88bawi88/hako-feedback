# hako-feedback

치지직 다시보기 주소를 넣으면 방송 피드백 리포트를 PDF로 만들어 주는 Windows 프로그램입니다.

## 받기

오른쪽 [Releases](../../releases/latest)에서 `HakoFeedback-Setup.exe`를 받아 실행하세요.

## 필요한 것

- Windows 10/11
- NVIDIA 그래픽카드(메모리 6GB 이상 권장). 없으면 받아쓰기가 매우 오래 걸립니다.
- 디스크 여유 15GB 이상
- Claude, ChatGPT, Gemini 중 하나의 계정

## 업데이트

프로그램 안의 [업데이트 확인] 버튼을 누르면 새 판으로 바뀝니다.
